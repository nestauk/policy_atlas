Evidence Search Pipeline

The twelve steps from a user's question to the final report, in run order. Red outlines are the only steps that remove documents. Blue pills are model calls, violet pills are models judging another model's output, outlined pills are plain code. Dots under the optional steps show which report preset runs them.

The twelve steps

#stepthe question it answerswho answersremoves documents?runs in
1acquireWhat should we search for? Fetch, merge, de-duplicate, keep up to the per-provider cap. Repeats as rounds at standard and deep depth.LLM query generationno (adds them)
2screenIs this document about the question? Title and abstract, three votes, two to keep. "Unsure" keeps. No abstract can only be excluded unanimously.LLM ×3yes
3classifyWhat kind of evidence is it? One of nine types, plus open method tags.LLMno
4appraiseHow strong is that type? Rubric lookup to a score of 1 to 5. Non-evidence and Unknown are skipped, which later makes them uncitable.codeno
5ingest full textFetch, parse, chunk and embed every screened-in document. A failed fetch keeps the abstract as the document's text, labelled.code + embedding modelno
6screen_fullWas step 2 right, now that the full text is here? One vote, demote only, never rescue.LLMyes
7characteriseWhat is the shape of the corpus? Deterministic coverage counts plus a two-call theme grouping of documents.LLM + codeno
8selectWhich documents get the expensive deep read? Stratified across themes, within a budget, honouring must-includes. Unselected documents stay citable.code (LLM rerank optional)no
9extractWhat does each selected document find? Intervention-outcome and implementation-context findings with verbatim anchor quotes, checked by code then by one vetter per kind.LLM 2 vettersno
10groupWhich findings are about the same thing? Clusters findings by intervention, outcome, population or barrier/enabler/mechanism theme. Does not decide the report's sections.LLMno
11synthesiseWhat does the evidence say? Proposes sections, writes each with read tools over the whole screened-in corpus, validates claims in code, judges every cited claim, repairs, then writes judged summaries.LLM agent grounding judge summary judgeno
12reportThe artefact the user reads: sections, claims with grounding tiers, verified citations, a reference list.output—
