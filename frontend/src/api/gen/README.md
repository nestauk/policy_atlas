# Generated API types

Two files here are generated by `openapi-typescript`. Do not edit them by hand.

- `types.ts` comes from `frontend/openapi.json`, the web API.
- `types-ops.ts` comes from `frontend/openapi-ops.json`, the ops service.

To remake them: `pnpm gen` and `pnpm gen:ops` from `frontend/`, or `make openapi-sync` from the
root. The make target also remakes both OpenAPI documents from the backend's request and
response models (`policy_atlas.api.contract`).

- `make drift-check` fails if any of the four files does not match the backend.
- ESLint does not check this folder, but TypeScript does: the files must type-check.
