# Generated API types

`types.ts` is generated by `openapi-typescript` from `frontend/openapi.json`. Do not edit it by
hand.

- To remake it: `pnpm gen` from `frontend/`, or `make openapi-sync` from the root. The make
  target also remakes `openapi.json` from the backend's request and response models
  (`policy_atlas.api.contract`).
- `make drift-check` fails if either file does not match the backend.
- ESLint does not check this folder, but TypeScript does: the file must type-check.
