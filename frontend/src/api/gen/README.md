# Generated API client

Everything else in this directory (`types.ts`) is generated by
`openapi-typescript` from `../../openapi.json` — run `pnpm gen`, or
`make openapi-sync` at the repo root to regenerate both together.

Do not hand-edit generated files here; `make drift-check` fails the build
if they stop matching the backend's Pydantic contract
(`policy_atlas.api.contract`). This directory is excluded from ESLint
(generated code is lint-exempt) but **not** from `tsc` — it must typecheck.
