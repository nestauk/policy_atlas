# Knowledge index

Durable, **verified** knowledge about Policy Atlas — how it's built, how it behaves, and the domain
it works in. Each entry is something a future contributor (human or agent) would otherwise re-learn
the hard way.

**Types are open** — OKF fixes no taxonomy. The bar is editorial, not categorical: *verified*,
*durable*, and *not already another lane's job*. Today's concepts are conventions, invariants and
testing rules (what task-001 proved); as the tool grows, expect domain concepts, architecture
explanations, integration quirks (real search / model providers), runbooks and deployment
assumptions too — add a new `##` section when a new kind arrives.

This is **not** the spec layer. `docs/specs/` holds *intent* — design decisions, some still 🟡 leaning
/ ❓ open. This holds what has been *built and verified*. Don't copy specs here; link to them.

Maintenance: add a concept **in the implementing PR** — after the review stack has finalised the code
([task cycle](../../.claude/skills/task-cycle/SKILL.md) step 8), before merge — written against the
code that shipped, so it can't drift from it. `/okf validate` and `/okf viz` are available for upkeep.

## Conventions

* [structlog is the only logger](logging-structlog.md) - all log calls go through structlog; no print / stdlib logging.
* [Tests run against a dedicated test database, each test in a rolled-back transaction](testing-database.md) - separate `policy_atlas_test` DB (conftest refuses the dev DB); the DB is a shared resource — parallel-lane fences include it, concurrent DB-backed pytest runs contaminate migration roundtrips (023 recurrence). [Index hook corrected at 023 step 8 — it still described the task-001 convention the concept itself records as flipped.]
* [Pure-Python vector maths on hot paths — math.sumprod + norms precomputed at construction](sumprod-hot-path-vector-maths.md) - stdlib beats a hand-rolled loop ~50-100× with zero deps (py≥3.12); extended-precision accumulation can reorder near-ties, so it's observable-change class — name the exception, keep ties key-stabilised (023 WP10c).
* [The unmarked-default naming smell — the first-built variant hoards the generic names](unmarked-default-naming-smell.md) - a second variant landing with marked names while the first keeps generic ones misreads as "the real one plus an add-on"; rename to symmetric marked names before external baselines pin the paths (023 IOF/ICF set; owner-caught, hence a recorded lens).
* [Reject model output at the grain of the fault — and persist the reason](validation-reject-at-fault-grain.md) - text-rule violations reject the unit and route it to repair; only id/envelope corruption rejects whole-response; rejection reasons persist with the run (012 fix via the 013 review stack).
* [Untrusted text enters prompts only as JSON-encoded records](untrusted-prompt-fields-json-records.md) - sanitization alone is not the boundary: the sanitizer preserves newlines, so raw interpolation lets a multi-line field fabricate template structure; every field rides inside `json.dumps`, allowlists re-validated at assembly (task 014 review stack, security lane).
* [A result cap belongs per call, not shared across a fan-out](result-caps-need-distribution-rule.md) - a shared total starves a fan-out from both directions: consumed serially, call #1 eats it and the rest are skipped (015 live check); divided across the fan-out, it shrinks as the fan-out widens (75 ÷ 15 = 5 results per query, 2026-07-30 hotfix). Size per call against the provider's page size; bound total volume separately, at acquisition, after merge and dedup — and never by a clock, which truncates the tail of an ordered fan-out (task 029).
* [Retiring a UI affordance is not retiring its grammar channel](retiring-ui-affordance-keeps-grammar-channel.md) - an option's rendering (button/row-editing) and its requires-input submission channel are separable; 028's retired "retype-everything" button nearly took the `edit_sections` channel with it, leaving no way to submit an edited list (lead-adjudicated restoration).
* [Content-keyed identity via uuid5 beats run-keyed uuid4 where fixtures pin byte-equality](content-keyed-ids-uuid5.md) - 028 theme_id = uuid5(project:name): stub-deterministic, rename-stable by construction (P2 rename keeps the id); honest scope — survives re-characterise only when the name reproduces byte-identically (F30 corrected the over-claim).

## Testing rules

* [Audit sanitized fixtures against the raw recording](sanitized-fixtures-audit-against-raw.md) - key-based sanitizers miss list-inherited keys and rare fields; substring-audit raw vs fixture, with a neutral fake lexicon.
* [A getattr-guarded SDK call silently no-ops across upgrades — and a stub shaped to it proves nothing](silent-sdk-guards-and-stub-shaped-tests.md) - langfuse 4.x removed `update_current_trace`; the guard skipped session attachment for every conversation while the stub tests passed; import optional SDK APIs loud, test the real mechanism (029 review, live-trace lane — sessionId null on every live trace).
* [Assert contract-required keys on the written row, not the component summary](assert-on-row-not-summary.md) - summary and row are built separately and drift; downstream readers consume rows — anchor evidence there (task 012 review stack).
* [Guard tests must assert the real invariant, or agents satisfy their letter](guard-tests-name-real-invariant.md) - the 007 zero-egress regex was dodged with `importlib.import_module("httpx")`; the honest move is extending the guard's stated invariant, and delegated executors optimise against the checks they are given (task 015 build).
* [Timing/politeness properties are asserted on an injected clock, not live logs](timing-asserts-injected-clock-logs-corroborate.md) - live log timestamps only corroborate; thread-scheduling jitter can put a sub-interval gap between two log lines even when the enforced spacing on the injected clock is correct (016 live check: one 0.845s/1.22s pair still summing to two 1.0s intervals).
* [Migration-roundtrip tests pin explicit revision targets and never hold seed rows across DDL](alembic-roundtrip-explicit-revisions.md) - a relative `"-1"` target silently retargets when later migrations land; uncommitted seeds on one connection block another connection's FK-dependent DDL — a 14-minute silent hang, not an error (017 build).
* [A deadline clock starting at Process.start() asserts "spawn + import < deadline"](process-start-deadlines-need-spawn-headroom.md) - under host load, child spawn plus package import alone can exceed a tight deadline, mislabelling a healthy worker as the timeout the test rules out; add spawn headroom or a start-signal handshake (017 build, 5s→20s).
* [pytest-socket denies only the current process and raises SocketConnectBlockedError](pytest-socket-process-local.md) - multiprocessing-worker guards must stay under the suite-wide deny; the allow-hosts-mode exception is NOT a `SocketBlockedError` subclass (019 A3, gate 4).
* [Live-only reachability is a real coverage class](live-only-reachability-coverage-class.md) - three 022 bugs passed a green 1300-test suite and fell over only live: live-model surplus behaviour (judge echo), enriched records re-entering strict wire validation, tracing-enabled-only branches; enumerate such branches at plan time and give them live checks or lifecycle-true fixtures.
* [Scoped dev-DB live checks drive one component via skeleton._run_component](run-component-driver-for-scoped-live-checks.md) - run row + plan compile + harness + tracing in one call, on the production execution path; reuse an existing screened selection, force DATABASE_URL after load_dotenv (020 live check).
* [Observe insertion order at the write seam, not by reading storage back](observe-order-at-the-write-seam.md) - plain `ctid` scrambles under page reuse, and `(created_at, ctid)` still ties on equal timestamps and scrambles within the tie (both failed for the extract write-order golden, build then review); a `before_cursor_execute` listener capturing insert params is deterministic by construction.
* [Parity across independent walks must compare structure, not raw UUIDs](structural-parity-uuid-canonicalisation.md) - per-walk first-seen UUID canonicalisation preserving referential structure; the broken literal comparison was written twice before the normalisation was pinned; prefer snapshot read-back over re-derivation for parity-critical fields (`completed_components`, the G2 pattern).
* [The suite is zero-egress by policy — scrub product-egress keys after loading .env](tests-are-zero-egress-scrub-keys.md) - conftest scrubs product-egress keys after `load_dotenv()`; alembic env reads `DATABASE_URL` via side-effect-free `dotenv_values()` since its own `load_dotenv()` re-poisoned the process on every migration fixture; API settings stay pure `os.environ`, backend mode explicit via `PA_BACKEND_MODE` (025 live-check finding).
* [Column-churning migration tests need a per-test scratch database](column-churn-migrations-need-scratch-db.md) - Postgres counts dropped columns toward the 1600-per-table tuple-descriptor limit, so a migration test that repeatedly adds/drops columns on the shared test DB permanently consumes slots until CREATEs fail; provision a scratch DB instead (025 build).
* [Mock-mode e2e tests validate contract shape, not wiring](mock-fetch-blindness.md) - mock mode intercepts at fetch, so the Playwright journey structurally cannot see transport/auth/base-URL/error-mapping/backend-composition bugs — all five 025 live-check integration bugs were in exactly that layer; Playwright's `reuseExistingServer` can also silently absorb the run into a leftover non-mock server; compensating control is the deferred thin real-HTTP smoke.
* [CDK synth tests — lookups only via the manifest; framework constructs add hidden Lambdas](cdk-synth-tests-lookups-and-hidden-lambdas.md) - a green synth proves nothing about `from_lookup` filters (CDK substitutes dummy context silently) — assert `manifest.json`'s missing-context queries; `triggers.Trigger` synthesizes a provider Lambda, so exactly-N-Lambda assertions exempt the framework (026 A.3).

## Integration quirks (infra / tooling)

* [SQLAlchemy execution_options belong on the statement, not the Connection](execution-options-statement-not-connection.md) - `.execution_options(yield_per=...)` set on a Connection is sticky and wraps every later statement executed on it; set it on the statement instead (`screen.py::_load_stage2_chunk_prefix`; three stage-2 tests went red at the 016 phase-3 gate before the fix).
* [uv run re-syncs to default-groups on every invocation](uv-run-resyncs-default-groups.md) - a CI dependency group lives in `[tool.uv] default-groups`, not an install step; the image excludes it with `--no-group` on every Dockerfile sync line, guard-tested (033 ops group).
* [pip-audit's -r mode SIGABRTs under uv-managed CPython on macOS](pip-audit-environment-mode-under-uv.md) - `-r` mode unconditionally builds a throwaway venv via ensurepip; environment-mode audit over the already-synced lockfile closure (`make audit`) gives identical local/CI coverage without the crash (016 deviation 1, confirmed by the review stack).
* [SSRF-safe IP pinning belongs in the NetworkBackend, not a rewritten URL](httpcore-origin-pooling-pinned-ip.md) - httpcore pools by URL origin and derives SNI/Host from it, not the dial target; pin the resolved IP in a custom `NetworkBackend.connect_tcp` (`fetch_live.py::_PinnedIPNetworkBackend`) rather than swapping the host in the URL, which corrupts pooling and SNI (016 plan-stage adversarial review blocker #3; also closes the TOCTOU re-resolve window).
* [The frontend's pnpm supply-chain posture, and where it bites](frontend-supply-chain-pnpm.md) - install scripts blocked (`onlyBuiltDependencies: []`), a 24h `minimumReleaseAge` that demonstrably rejected four real <24h packages during the build (pin next-older releases, don't exclude), exotic-subdep blocking, strict `node_modules`; Node 25 dropped bundled corepack; vitest's default glob collects Playwright specs under `e2e/` unless excluded.
* [Vite 8 / plugin-react 6 wire the React Compiler through a separate babel plugin](vite8-react-compiler-wiring.md) - the classic `react({ babel: {...} })` option is gone in the Rolldown era; wiring goes through `@rolldown/plugin-babel` + `reactCompilerPreset`; verify it ran by grepping the bundle for `useMemoCache`.
* [CloudFormation re-asserts a template value only on a changed deploy](noop-deploys-dont-reassert-template-pins.md) - the pinned `DesiredCount=0` doesn't stop a scaled-up service on a no-op deploy; deploy.sh scales down explicitly (026 E.2); same mechanism means SSM-coupled consumer stacks skip deploys after a producer resource is replaced — force-redeploy + reset stale `cdk.context.json`.
* [PyJWT verifies aud by default whenever the claim is present](pyjwt-aud-verified-by-default.md) - no `audience=` argument ≠ no check; Cognito access-token semantics need `verify_aud: False` + hand-rolled `token_use`/`client_id` checks, and the conformance suite proves the generic path stayed dead (026 C.2, plan-adv F9 held).
* [docker save layout depends on the daemon's image store](docker-save-layout-image-store.md) - containerd store → OCI `blobs/sha256/*`, legacy → `*/layer.tar`; a scanner globbing one shape cleanly passes over nothing; exempt CA trust stores (certificates), not keys (026 A.4/E).
* [uv src-layout images: deps layer via --no-install-project, project via a second sync](uv-src-layout-image-pattern.md) - cacheable dependency layers + a real installed `policy_atlas` package, no PYTHONPATH hacks; pin the uv binary's image tag (026 A.4 + review).
