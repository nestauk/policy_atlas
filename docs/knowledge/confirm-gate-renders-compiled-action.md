# Rule

"Nothing applies unconfirmed" is necessary but not sufficient: the confirm
surface must show **the compiled action** (the bounded, scrubbed delta that
will apply), not only the model's own summary of it — a router summary is the
author grading its own work. Live evidence (024 pinned runs): a fluent
summary + accurate fan-out routing still hid that "drop any section about
methodology" had compiled to *replacing the whole 8-section proposal with one
generic section*, and that "Select fewer documents" had compiled to the
*unchanged* budget. Both were confirmed; both events were honest; the user
could not have known.

Corollaries: (1) an **LLM-authored option** that triggers a destructive
change (replacement re-run) needs its own plain-language mode declaration +
y/N before applying, even though the user "picked" it — the label is also
model-authored; (2) when **every** fragment of a steer is refused, render the
per-fragment reasons — a bare "could not be applied" hides the refusal
honesty the events already carry; (3) canonical option labels that trigger
re-runs declare it in words ("re-runs selection, replacing the current one").
The record being rebuildable (events) does not substitute for the moment of
consent being informed.
