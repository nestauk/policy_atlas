# Nesta brand tokens — for Policy Atlas hi-fi wireframe

Extracted from *Nesta Visual Identity 2.0* + *Shared component library* (AFS).

## Typography
- **Zosia Display** — bespoke headline font. Short, snappy headlines only (1–2 lines), never body/sub-heads. (Not web-available → hi-fi fallback: a strong geometric display, e.g. "Anton"/"Archivo"/system; flag as placeholder for real Zosia.)
- **Averta** — core typeface. Weights used: **Bold** (sub-headlines), **Semibold** (secondary titles), **Light** (body + captions). (Not on Google Fonts → closest free fallback: **Mulish** or **Manrope**.)
- **Century Gothic** — system fallback for external docs.
- Hierarchy: headline = Zosia Display; sub-head = Averta Semibold; body/caption = Averta Light.

## Colour — core palette
- **Electric Blue `#0000FF`** — hero colour, centre of the palette.
- Primary: Green `#18A48C`, Red `#EB003B`, Orange `#FF6E47`, Yellow `#FDB633`, Purple `#9A1BBE`, (+ Blue).
- Secondary: Aqua `#97D9E3`, Violet/Lilac `#A59BEE`, Pink `#F6A4B7`, Sand `#D2C9C0`, Navy `#0F294A`.
- Neutrals: Dark Grey `#646363`, Black `#000000`, White `#FFFFFF`.
- **AFS (A Fairer Start) tool palette**: 4 primary = Nesta blue, yellow, lilac (`#A59BEE`), orange; 4 secondary = sand, aqua, purple, navy.
- Lead with ONE hero colour per layout. Always check accessibility. (Scotland: avoid blue/orange pairing.)
- Gradients: steps at 100 / 70 / 40 / 20.

## Buttons (from AFS component library)
- **0px corner radius with 45° cutouts** — distinctive Nesta button shape.
- **Primary**: solid Nesta blue, white Averta Regular text. One per view.
- **Secondary**: text only, subtle grey background on hover.
- **Ghost**: low emphasis (Cancel, Back to top).
- **Disabled**: present but not clickable.
- Padding: 16px L/R, 12px T/B. Auto-layout (expands to label).
- Labels: **sentence case**, action-oriented ("View tactics", not "Click here").
- Icons: left = context, right = forward motion (arrow); same colour as text.

## Navigation
- "**Growing underline**" active state: current page in Averta Bold + full Nesta-blue underline (fills container width). Default: Averta Regular, no underline.
- Left = brand group (Nesta logo + tool title). Right = nav links.
- Container 1440px, 80px side padding, full-bleed background fill.
- Nesta grey text on white = AAA. Use contrast checker over images.

## Homepage hero pattern
- Main nav bar + captivating static image + **blue statement box** (Nesta homepage mirror).

## Logos
- Mission logos (stacked in nav, single-line in footer). AFS = "A Fairer Start".
- Never recreate the logo; use master artwork.
