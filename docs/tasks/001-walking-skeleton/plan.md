  Build may begin at Phase 0.
- **Scope:** [contract.md](contract.md) is authoritative; this is the *how* and *order*. Build is
  topological — every step lands a check before the next. The contract's *Stop conditions* apply.

## Clarifications resolved (from the readiness review — fold these in)

- **`make build` = `uv build`** (the unmapped verify target). See [ADR 0001](../../adr/0001-walking-skeleton-foundations.md) §11.
- **Docker image = plain `postgres:16`**, no pgvector extension this slice (no vector columns).
- **"synthesise (stub)" = `produce-grounded-block`'s internal step**, *not* EB component #9. The one
  trivial component is named **`echo`** to avoid the collision.
- **Synthetic source fixture lives in a shared module** (`policy_atlas` package, not `tests/`) so the
  runtime entrypoint *and* the test suite both load it.
- **`sequence`** assigned app-side `max+1` per project (serial single-writer); **append-only enforced
  at the repository layer**.
- **Doc nit:** ✅ fixed — contract *Stop conditions* now reads "beyond the **seven** listed".

## Build order

### Phase 0 — toolchain & command surface (lands `make verify` green, no app logic)

1. **uv project** — `pyproject.toml`, `src/policy_atlas/` layout; pin deps (langgraph, pydantic,
   sqlalchemy, psycopg, alembic, structlog) + dev (pytest, ruff, mypy). Configure ruff, mypy
   (strict), pytest in `pyproject.toml`.
2. **structlog config** — one logging-setup module imported at entrypoints; JSON in deploy, console
   locally.
3. **Docker Compose** — `docker-compose.yml` with `postgres:16` + healthcheck; `.env.example`
   (`DATABASE_URL`).
4. **Wire the Makefile** — `setup`→`uv sync` + compose-up + wait-for-ready; `test`→`uv run pytest`;
   `typecheck`→`uv run mypy`; `lint`→`uv run ruff check`; `build`→`uv build`; `verify`→ ensure DB up
   (or fail with a clear setup error) then `test typecheck lint build`.
   - **Check:** `make verify` green against one trivial passing test; `make setup` brings the DB up.

### Phase 1 — persistence (schema + migration)

5. **Table metadata** — SQLAlchemy Core definitions for the seven tables + the three constraints
   (event_log unique `(project_id, sequence)`; addressable_unit unique `(block_id, unit_id)`;
   annotation composite FK). No deferred columns.
6. **Alembic** — init; one migration creating all seven tables (autogenerated from metadata, then
   read by hand). No `CREATE EXTENSION`.
   - **Check:** migration applies to a fresh DB; **schema-validation test** (tables/columns/
     constraints present); **composite-FK rejects** a mismatched `(block_id, unit_id)`; unique
     constraints hold.

### Phase 2 — spine modules (each thin, behind an interface)

7. **Inference seam** — `InferenceProvider` protocol + `StubEchoProvider` (canned text, no egress).
8. **Event-log repository** — `append(project_id, run_id, event_type, payload)` assigning
   `sequence = max+1` per project; `read(project_id)` ordered by `sequence`. No update/delete method.
   - **Check:** append/read-back in deterministic `(project_id, sequence)` order.
9. **Plan → config compile** — trivial `Plan` (pydantic) → `Config` (pydantic) deterministic mapping;
   invalid input raises a caught `CompileError` (no silent run).
   - **Check:** compile produces the expected config; invalid plan raises and does **not** run.
10. **`produce-grounded-block` (deterministic leg)** — synthesise (stub) → cite → verify (verbatim
    quote-presence, normalised match vs the shared synthetic fixture) → write block + unit + citation
    annotation (`{source_ref, quote, verification_result}`). Fabricated quote → hard fail recorded,
    no clean tier.
    - **Check:** quote-presence **pass**; fabricated-quote **hard-fail**; content-hash stable.
11. **LangGraph harness** — fixed graph: compiled config → run the `echo` component (calls
    produce-grounded-block) → block-boundary commit (one event) → set run status. In-process.
    - **Check:** **run record** created → reaches `succeeded`/`failed` deterministically → reads back.

### Phase 3 — end-to-end thread & evidence

12. **Runnable entrypoint** — e.g. `python -m policy_atlas.skeleton`: create project + run, build the
    trivial plan, compile, run the harness, persist artefact/block/unit/annotation, append the six
    events, print persisted IDs + the ordered event log. Loads the shared synthetic fixture.
    - **Check:** the manual thread runs; the **six event types** (`run.started` · `plan.compiled` ·
      `component.started` · `component.completed` · `block.written` · `run.completed`/`run.failed`)
      appear in order.
13. **Fill [verification.md](verification.md)** — command results, persisted IDs, the exact thread
    command, diff summary, public-safety confirmation.
