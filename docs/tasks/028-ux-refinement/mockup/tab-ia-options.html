For

  • One home for "what the evidence looks like" — readers meet it in reading order, inside the report they'll share.
  • Five tabs; the nav carries only destinations users named in interviews.
  • The funnel/coverage story sits beside the findings it qualifies — honesty next to the claims.

Against

  • The report gets longer; the section is one more thing to scroll past (mitigated: collapsed by default, sidebar jump).
  • Chart-first users lose a one-click destination — it's two clicks (Evidence base → section).
  • During a run there is no artefact yet, so these charts are only in the journey pane until the report exists (true today too — Landscape is empty pre-run).

What changes: nothing structural — six tabs stay. The Landscape tab keeps its own page (below, as today, restyled to the 028 type scale); the evidence base keeps Key themes but never shows the funnel or distributions.
