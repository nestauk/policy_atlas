For

  • One home for "what the evidence looks like" — readers meet it in reading order, inside the report they'll share.
  • Five tabs; the nav carries only destinations users named in interviews.
  • The funnel/coverage story sits beside the claims it qualifies — honesty next to the findings.

Against

  • The real contents list is already ~10 long, question-specific titles — the folded section is an eleventh entry in an already-dense sidebar.
  • Chart-first users lose a one-click destination — it's two clicks (Evidence base → section).
  • Pre-run there is no report page at all, so the gathering story only exists in the journey pane until synthesis completes (true today too — Landscape is empty pre-run).

What changes: nothing structural — six tabs stay. The Landscape tab keeps its own page (below, restyled to the 028 type scale); the report page keeps its ten real sections and never shows the funnel or distributions.
