How "how thorough?" is asked — ruled

One question, three outcome-labelled presets + free-text custom mixes (owner, 2026-08-04). The machinery's two axes (search effort · analysis depth) compile from the preset; free text reaches any mix.

Option A — one question, three presets + customise (recommended)

Quick look = rapid search · landscape depth (~10 min) · Standard review = standard · standard (~20 min) · Deep analysis = deep · deep, findings extracted (~45 min). A quiet "customise" exposes both axes — the scripted user's rapid+standard mix is covered by no preset. Free text compiles any mix.

Option B — two questions (search, then analysis)

Every combination button-reachable — but a fifth turn, and the finding-vs-reading distinction needs explaining every time.
