renames (i) *identifiers* from an explicit per-symbol table and (ii) *path-like
string literals* matched by an explicit pattern list. It never touches free
prose, copy modules or docs bodies (P1). The identifier table is generated by
the script's `--scan` mode (every identifier in the file set containing a
token, with its proposed target) and reviewed by the lead before `--apply`;
the reviewed table is committed beside the script.
