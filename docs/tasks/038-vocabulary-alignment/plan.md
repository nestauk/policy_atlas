## Decisions fixed here (lead seam design)

D1. **Token map.** The sweep replaces whole tokens inside identifiers, path
segments and string literals, case-preserving (`project`/`Project`/`PROJECT`,
plurals, and the compound forms `project_id`/`projectId`/`ProjectOut`), in
this order and nowhere else:

| Step | Token | → | Notes |
|---|---|---|---|
| 1 | `project_source_snapshot` / `pss` (constraint infix) | `task_source_snapshot` / `tss` | before the bare token |
| 1 | `orchestration_plan` (table string) | `plan` | manifest |
| 1 | `orchestration_plan` (Python identifier, module) | `task_plan` (`task_plan.py`) | a variable named `plan` already exists in the callers |
| 1 | `OrchestrationPlan` | `TaskPlan` | `Plan` is the wire shape |
| 1 | `orchestrator` / `Orchestrator` / `ORCHESTRATOR` | `agent` / `Agent` / `AGENT` | incl. `OrchestratorBackend`, `OpenAIOrchestratorBackend`, `StubOrchestratorBackend`, `get_orchestrator_backend`, `_SteerPointOrchestrator`, `default_orchestrator`, `orchestrator_prompt.py`, `orchestrator_backend.py`, log/span names, env vars |
| 1 | `orchestrate` (module, `OrchestrateResult`, `_orchestrate_cleanup`, `test_orchestrate`, log `orchestrate.start`) | `agent` (`agent.py`, `AgentResult`, `_agent_cleanup`, `test_agent`, `agent.start`) | contract V4 |
| 1 | `Orchestration` (8 sites) | reported, lead decides per site | not auto-mapped |
| 1 | `project` / `projects` | `task` / `tasks` | the entity token |
| 1 | `evidence_base` / `evidence-base` / `Evidence Base` | `evidence_search` / `evidence-search` / `Evidence search` | package, capability key, spec dir, prose title |
| 1 | `evidence_base_coverage` | `evidence_search_coverage` | falls out of the previous row |
| 2 | `portfolio` / `portfolios` (+ `Portfolio*`, `portfolio_id`, `portfolioId`) | `project` / `projects` … | runs only after step 1 has left no `project` token in the file set, so it cannot collide |

`docs/agentic-ops/failure-log.md` and `backlog.md` (history),
`backend/alembic/versions/*` except the new file (a migration describes the
schema at its own revision), `backend/tests/core/test_*migration*.py` and
`test_migrations_0*.py` (they assert on historical names; updated by hand in
Phase 3b), `.claude/`, `.cursor/`, `node_modules`, `.venv`, `cdk.out`.

D3. **Two-step order is the collision guard.** Step 1 runs to completion
across the whole file set before step 2 starts. A dry run lists every match
the map does not cover, with three lines of context; the lead approves the
exception list before the real run. The script is idempotent: a second run
reports zero changes (I-sweep).

D4. **Collision audit (before the sweep).** Frontend: `useCreateProject` →
`useCreateTask` collides with the live `useCreateTask` — resolved by deleting
the dead hook in Phase 1 (V12). No other collision: the existing `Task*`
names (`TaskListPanel`, `TaskListRow`, `taskDestination`, `useCreateTask`,
`task_count`) have no `Project*` counterpart. Backend: no `task_*`, `Task*`,
`agent_*` or `Agent*` identifier exists except `task_count` and the event kind
`agent_judgement_routed`, both kept. `Plan` (wire shape) is why the runtime
class becomes `TaskPlan`. The script re-checks all of this at run time and
refuses to rename onto an existing symbol.

D5. **Stored-value compatibility lives in three helpers, not scattered.**
`steering_events.canonical_actor()` (A5); a `mode="before"` validator on the
steer-point field of `TaskPlan` plus the same map in the pause-record reader
(A3); `_EVENT_KINDS` accepting both generations of the four `task.*` kinds
(A4). Each has a test that feeds the old value and asserts the new one out.

D6. **Downgrade reverses values, not just names** (A2): the revision's
`downgrade()` runs the manifest in reverse and then four `UPDATE`s
(`capability`, `event_type`, JSONB `decided_by`/`authored_by`, JSONB steer
point) scoped to the new values. The round-trip test asserts a pre-migration
fixture is byte-identical after upgrade → downgrade.

D7. **V11 seam** as pinned in the contract: the callback keeps its
`replaceState`; `App.tsx` navigates the freshly mounted authenticated router
to `window.location` once when status becomes `authenticated`.

D8. **knip rule** (A13): an unused export that is referenced inside its own
file loses the `export` keyword; one referenced nowhere is deleted; tests,
e2e and the dynamic imports in `routes.tsx`/`main.tsx` count as references.
Exceptions: `App` keeps its default export (drop the named one);
`playwright.fe-api-smoke.config.ts` stays. The full knip list from the
contract is the worklist; `verification.md` records the disposition per item.
